# Контекст платформы для помощника

Проверено по исходникам рабочего checkout, 13 ноября 2026. Это карта для поиска, не обещание текущего состояния серверных данных.

- Платформа: https://ivan100.ru. React + Vite; сервер Node/Express: `server/index.js`; клиентские запросы: `src/services/api.js`.
- Есть индивидуальные, групповые и пробные занятия. Голосовая комната, общая доска и общий Python-код — разные поверхности одного урока. Страница задачи из «Изучения Python» и общий код урока — тоже разные механизмы.
- Задачи Python имеют темы, подразделы, тесты и прогресс отдельного ученика. Отсутствие точной информации о странице ученика не доказывает, что он отключился от звонка.
- У заданий могут быть исходный файл, история сохранённых решений и общий готовый разбор. Сохранение в Excel, доставка совместных изменений и сохранение файла на доску могут расходиться при сбое.
- Workbook Helper подключается к Excel/LibreOffice. Есть резервное обычное открытие с сохранением. Не предлагай перезагрузить весь компьютер и удалить локальную работу без необходимости.
- Входные файлы Python-задач, вложения на доске и вручную выбранные файлы в «Ввод и файлы» нужно различать. Для жалоб на чтение файла нужны имя в `open(...)`, вложение и ошибка.
- Исходники Telegram-шаблонов: `server/messageTemplateTelegram.js`. Этот существующий бот обслуживает видео/шаблоны и уже может иметь webhook. Новый помощник не должен забирать его обновления или менять webhook.
- Контакты ученика и родителя хранятся раздельно: `server/privateStudentContacts.js`, `/api/student-contacts` и `/api/student-parent-contacts`. Сверка относится только к ученикам Ивана; административный список без фильтра владельца может включать чужих учеников. Актуальные группы проверяются по активному членству, а не по имени контакта или старым сообщениям.
- С 13 ноября 2026 к локальному приёмнику подключён отдельный production-источник только на чтение: `/api/reply-assistant/directory`. Он выдаёт имена, Telegram-привязки, роли «ученик/родитель» и группы только учеников Ивана. Отдельный ключ не даёт доступа к кодам входа, финансам, журналам или изменению данных. Приёмник сверяет отправителя и кладёт только его совпадения в `platformIdentity` нового пакета; учитывай статус и `checkedAt`. Снимок обновляется через 5 минут, старше 20 минут не используется для подтверждения. Старый пакет не является свежей проверкой.
- Пробники разделены по учителям. Публикация «всем» относится к ученикам владельца. Чужие ученики/ответы/учётные данные недоступны помощнику по умолчанию.
- В №25 пробника 12 строк по 2 поля, заполнение по строкам. Дополнительные пустые строки допустимы.

Для конкретного вопроса ищи соответствующие модули через `rg` и читай только нужные участки. Не считай файлы `server/data` локального checkout копией актуальной production-базы. Не открывай `.env`, auth-сессии, ключи, коды учеников и личные данные, не относящиеся к обращению.

Для нового выпуска эту карту нужно сверять с изменёнными исходниками и проверенными заметками релиза. Не заменяй фактическую проверку пересказом старого обсуждения.

Вероятные ошибки передаются через `technicalIssue` в квитанции приёмника в существующий чат разработки. Это передача на проверку, а не доказательство ошибки или уже выполненного исправления. Подтверждённый результат приходит отдельным служебным пакетом, который не нужно отправлять на проверку повторно.
