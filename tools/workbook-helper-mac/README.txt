IVAN100 — помощник таблиц для macOS, тестовая версия 0.1.0

Установка
1. Распакуйте ZIP. Откройте «Установить.command» в Finder.
2. Если macOS просит подтвердить открытие файла из интернета, используйте
   стандартное подтверждение macOS только для этого скачанного с ivan100.ru
   установщика. Если запуск запрещён политикой вашего Mac, используйте
   «Скачать» на платформе. Отключать защиту macOS не требуется.
3. Установщик скачает Node.js 22.23.3 с официального nodejs.org и проверит
   заранее закреплённую SHA-256. Первый запуск требует интернета, ~50 МБ.
4. Откройте на сайте задание и нажмите «Решать» / «Открыть в LibreOffice».
   Разрешите браузеру открыть «IVAN100 Таблицы», когда он это предложит.

Нужны macOS 11+, LibreOffice или Microsoft Excel. Помощник сам не устанавливает
офисный пакет. Работают Apple Silicon и Intel. Установка без прав администратора.
Приложение появится в ~/Applications/IVAN100 Таблицы.app. Токены доступа хранятся
только в памяти. Автозапуск при входе в macOS не добавляется.

Работа
Изменяйте таблицу и сохраняйте Cmd+S. При первом изменённом сохранении выберите
название решения. На сайте решение появится под исходным заданием. На Mac текст
задания 26/27 открывается отдельно в TextEdit; работа сохраняется в таблице.
Изменения отправляются после завершения записи файла, одинаковые версии повторно
не создаются. При недоступном интернете помощник повторит отправку. При конфликте
версий, окончании срока доступа или отмене доступа локальные файлы сохраняются,
а отправка останавливается: откройте работу с сайта заново.

Лучше использовать обычное «Сохранить». «Сохранить как» поддерживается только
для новой таблицы того же формата в этой же отдельной папке работы. Другая папка,
другой формат или несколько новых копий одновременно не отслеживаются.

Откройте приложение «IVAN100 Таблицы», чтобы проверить состояние, повторить
отправку, открыть папку решений или остановить помощник. После его остановки
откройте нужное задание с сайта снова. Все локальные копии находятся в:
~/Documents/Иван на сотку/Решения/ (отдельная папка для каждого запуска).
Помощник не удаляет эти файлы автоматически.

Безопасность
Поддерживаются .xls/.xlsx/.xlsm/.xlsb/.ods/.fods. Помощник принимает только ссылки
https://ivan100.ru, проверяет привязку, хеш и версию файла; скачанным документам
ставится защитная метка macOS до открытия. Включать макросы для решения задач
не требуется. Помощник не меняет настройки макросов или защиты Office/macOS.

Это первая тестовая версия macOS. Протокол, загрузка, сохранение и конфликты
проверены автоматическими тестами; установка, AppleEvents и открытие в Excel/
LibreOffice на настоящем Mac ещё не проверены. Приложение создаётся локально
через стандартный osacompile; Apple Developer подписи и нотариализации нет.
Кнопка «Скачать» на платформе всегда остаётся доступной.
