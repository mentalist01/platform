Иван на сотку — помощник таблиц для Windows 10/11 x64
Официальная страница: https://ivan100.ru/workbook-helper/

УСТАНОВКА
1. В Проводнике нажмите на ZIP правой кнопкой и выберите «Извлечь всё».
2. Откройте распакованную папку и запустите IvanEgeWorkbookHelper.exe.
3. Подтвердите установку для своей учётной записи Windows.
4. Вернитесь на ivan100.ru и нажмите «Решать через помощник таблиц».
Нужен установленный Microsoft Excel или LibreOffice Calc. Устанавливать .NET отдельно не требуется.

ОБНОВЛЕНИЕ
Сначала сохраните открытую таблицу через Ctrl+S. В значке помощника возле часов выберите «Выход», затем запустите новую версию из распакованной папки.

ЧТО УСТАНАВЛИВАЕТСЯ
Программа устанавливается в %LOCALAPPDATA%\IvanEge\WorkbookHelper.
Регистрируется ссылка ivan-ege:, чтобы сайт мог открывать учебную таблицу.
Права администратора и автозапуск Windows не используются. Помощник не устанавливает расширения браузера и не меняет настройки защиты.
Учебные таблицы и изменения выбранной общей таблицы передаются на ivan100.ru по защищённому соединению. Помощник не получает пароль или браузерную сессию сайта. Личные документы, которые вы сами открыли в офисной программе, к общей таблице не подключаются.

ПОДПИСЬ И ПРОВЕРКА
Сведения о текущей версии, наличии подписи и SHA-256 размещены на официальной странице помощника. Контрольная сумма подтверждает совпадение файла с опубликованной копией и сама по себе не является заключением антивируса.
ZIP не отменяет проверок Chrome и Windows. Если защита сообщает о конкретной угрозе, передайте преподавателю точный текст сообщения и версию файла.

УДАЛЕНИЕ
Сохраните таблицы, выберите «Выход» в значке помощника возле часов и удалите папку %LOCALAPPDATA%\IvanEge\WorkbookHelper. Сохранённые решения в папке «Иван на сотку» на рабочем столе удалять не нужно.
Если после удаления нажать «Решать» на сайте, ссылка больше не сможет открыть помощник. Для повторной работы установите его заново.
