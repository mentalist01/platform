# IVAN100 Учитель — первая версия для Windows

Приложение для преподавателя: кабинет ivan100.ru, звонки, доска, домашние задания, отдельные окна пульта и архива. Ученики продолжают пользоваться сайтом.

## Установка

1. Запустите `IVAN100-Teacher-0.1.1-Setup.exe`. Установка — в аккаунт текущего пользователя Windows 10/11 x64. Администратор для обычной установки не нужен.
2. Откройте ярлык **IVAN100 Учитель** и войдите в свой аккаунт преподавателя. Вход в приложении отдельный от браузера; затем сохраняется в профиле приложения.
3. **Пульт записи** сверху открывает установленный помощник. **Архив и теория** открывает его архив. Окно кабинета и звонок при этом остаются открытыми.
4. Если помощника ещё нет: нажмите **? → Открыть «Запись уроков»**, скачайте пульт и выполните инструкцию. Используйте код подключения из своего аккаунта преподавателя.

Пульт и OBS продолжают работать отдельно. Приложение не переустанавливает помощник, не меняет его настройки, не переносит и не удаляет записи. Если установленный пульт остановлен, кнопка пульта запускает его штатный `background.vbs`.

## Перед первым уроком

- В пульте 1.4.8 или новее на основном экране обновите список окон и выберите **[IVAN100-Teacher.exe]: IVAN100 Учитель** в поле **«Окно для режима “Платформа”»**. Старый выбор окна Chrome/Edge остаётся прежним до вашей настройки. Если разговор записывался из того же окна, его звук переключится вместе с изображением; отдельно выбранный Телемост сохранится. В прежних версиях выберите приложение в мастере как изображение платформы и источник звука разговора. Во время урока оставляйте приложение открытым и не свёрнутым.
- Для автоматического возврата из LibreOffice в окно приложения используйте пульт версии **1.4.7** или новее. Обновляйте пульт между уроками, после окончания записи и загрузки.
- Проверьте короткую тестовую запись с изображением, своим голосом и голосом собеседника. Сетевые звонки используют действующее соединение платформы.
- При первом включении камеры или микрофона приложение спросит разрешение для ivan100.ru. Его можно сбросить через **Alt → Приложение → Сбросить разрешения камеры и микрофона**.
- Для демонстрации выберите **Кабинет платформы**, **Окно программы** или **Весь экран**. Звук выключен по умолчанию. Для окна/экрана галочка передаёт звук всего компьютера, включая уведомления.

## Каждый день

- После успешного входа код преподавателя сохраняется на компьютере с шифрованием Windows. На странице входа нажмите **Выбрать сохранённый код** или **Входы** справа сверху. Выбранный код подставится в форму; нажмите **Войти**. Можно сохранить несколько преподавателей. Крестик в списке удаляет сохранённый код. Если шифрование недоступно, приложение продолжает работать без сохранения кодов.
- Картинки и документы автоматически сохраняются в папку Windows **Загрузки**. Одноимённые файлы получают номер; существующие файлы сохраняются. Панель **Загрузки** справа сверху (или `Ctrl+J`) показывает ход скачивания. Готовый файл можно перетащить из неё на доску, в мессенджер или другую программу. **Очистить список** убирает историю, а сами файлы остаются в папке.
- Расширения Chrome/Edge в приложение не переносятся. Чтобы смотреть с вашим блокировщиком рекламы, откройте видео через ссылку «Открыть на Rutube» в браузере, где установлено расширение. Встроенный плеер приложения показывает рекламу по правилам Rutube.

- `Ctrl+1` — вернуться к кабинету, `Ctrl+2` — пульт, `Ctrl+3` — архив.
- `Alt` — меню приложения, `F11` — полный экран, `Ctrl+R` — обновить кабинет (обновление страницы прерывает текущий звонок).
- Перед закрытием приложения завершите урок на платформе. Закрытие окна прерывает звонок; пульт и очередь загрузки работают отдельно.
- Если интернет пропал, появится кнопка повторного открытия кабинета. Автоматического обновления посреди урока нет.

## Обновления и границы первой версии

Кабинет загружается с **https://ivan100.ru** и получает изменения вместе с сайтом. Без интернета кабинет недоступен. Для обновления самой оболочки нужен новый установщик. Удаление приложения сохраняет профиль входа; на чужом компьютере перед удалением выйдите из аккаунта на платформе.

Сборка 0.1.1 пока без цифровой подписи издателя. Windows может предупредить об неизвестном издателе. Для подписанных общедоступных выпусков нужен сертификат подписи или настроенный сервис подписания.

Системные push-уведомления при полностью закрытом приложении и автоматическое обновление оболочки в эту версию не входят. Уведомления в открытом кабинете работают по правилам платформы. Проверка на живом уроке и разных аудиоустройствах нужна до замены браузера в ежедневных занятиях.

## Разработка

```powershell
cd tools/teacher-desktop
npm ci
npm test
npm start
npm run dist
```

Установщик и распакованная сборка появляются в `output/teacher-desktop/release`. `npm run icons` пересоздаёт иконки из `public/logo1.png` (нужен `sharp` основного проекта).

Веб-контент работает в песочнице без Node.js. Узкий мост основного фрейма ivan100.ru сохраняет успешный вход и открывает локальный выбор кодов; сайт не может читать список кодов или скачанных файлов. Подстановка кода происходит только по выбору пользователя в локальной панели. Привилегированные файловые кнопки находятся в отдельных локальных страницах. Камера/микрофон разрешаются только основному фрейму ivan100.ru. Внешние веб-ссылки открываются в браузере; произвольные локальные службы и системные протоколы блокируются. Профиль разработки отделён от установленного приложения.
