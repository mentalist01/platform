# Эксперимент: синхронизация Excel ↔ LibreOffice

Отдельный прототип для проверки технической возможности. Не включён в сайт и установленные помощники, не подключается к данным учеников. Передача файла на уроке работает по-прежнему.

## Что проверяет

- Числа, текст, простые формулы и сплошную заливку отдельных ячеек.
- Изменения передаются между реально открытыми Excel и LibreOffice без Ctrl+S.
- Формула вычисляется самим офисным приложением, а не сервером.
- Правки содержимого и заливки учитываются отдельно, даже внутри одной ячейки.
- Конфликт двух изменений одного свойства сохраняет обе версии до явного выбора.
- Повторная отправка после потери ответа не дублирует операцию.
- Перед применением чужого изменения приложение повторно сравнивает ячейку с ожидаемым значением, чтобы не затереть правку, сделанную во время запроса.

Локальный HTTP relay слушает только `127.0.0.1`, использует отдельные случайные токены для участников и не принимает браузерные cross-origin запросы. Токены сайта и пути личных документов ему не передаются. LibreOffice запускается с новым отдельным профилем и именованным каналом UNO, Excel — новым экземпляром. Макросы отключены.

## Запуск проверки на Windows

Нужны .NET 9, установленный Excel и LibreOffice со встроенным Python, Node.js.

```powershell
dotnet build tools/workbook-live-prototype/excel/WorkbookLiveExcel.csproj -c Release
node --test tools/workbook-live-prototype/sync.test.mjs
node tools/workbook-live-prototype/real-office-check.mjs output/workbook-live-check-new
```

Папка проверки должна быть новой. Отчёт, отдельные файлы `Excel-merged.xlsx` и `Calc-merged.ods` остаются в ней. Процессы эксперимента закрываются после проверки; ранее открытые документы не закрываются.

Для интерактивной проверки:

```powershell
node tools/workbook-live-prototype/demo.mjs
```

Появятся две новые таблицы. Измените B2 в Excel и B3 в LibreOffice: число и пересчитанный итог должны появиться в обеих. Можно менять заливку и вводить значения в A1:D8. Для завершения в консоли введите `stop`. `--seconds 60` автоматически завершает тест через минуту.

## Пределы эксперимента

- Проверяется только лист `Live` и указанный диапазон, не вся книга. Опрос по умолчанию — раз в 350 мс, сканирование последовательное внутри каждого адаптера. Такой способ нельзя без измерений распространить на сотни тысяч ячеек.
- Нет интеграции с существующим Windows/macOS помощником, боевой авторизации, хранения операций на сервере, восстановления полного сеанса после перезапуска и сохранения результата на доску.
- Нет адаптера Excel для Mac, реального тестирования на Mac или между разными компьютерами. Проверка Windows Excel ↔ Windows LibreOffice доказывает обмен между движками; переносимость на другие сочетания пока не подтверждена.
- Не поддерживаются сортировки, вставка/удаление строк и столбцов, листы, объединения, условное форматирование, Undo и произвольные формулы. Не используйте их в интерактивном тесте. Без обработки этих операций включать режим на уроке нельзя.
- Внутренний формат формул ограничен простыми совместимыми формулами. Преобразование разделителей сохраняет строки в кавычках, но не заменяет полноценный парсер формул. Массивы и внешние ссылки отклоняются.
- Нужны журнал, понятное окно конфликтов, индикатор связи и отдельная логика Ctrl+S для общей серверной версии. Нельзя одновременно разрешить старый upload целого файла и cell-sync без проверки версии: старое сохранение может затереть общие изменения.

## Следующий этап

Подключить уведомления о реально изменённых диапазонах вместо сканирования всей книги; добавить журнал и сохранение общей версии; проверить структурные операции, большие таблицы и macOS. Затем вводить как отдельный экспериментальный режим помощника с сохранением прежнего режима работы.
