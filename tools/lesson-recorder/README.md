# Запись уроков IVAN100 на компьютере

Помощник для Windows связывает занятие на платформе с OBS Studio и Rutube. Видео остаётся на компьютере; платформа хранит только состояние обработки и закрытую ссылку. Старые записи уроков продолжают открываться прежним способом.

## Один раз настроить

1. Установить OBS Studio 28 или новее, Node.js 22, ffmpeg и Microsoft Edge. Запустить `install.ps1` из PowerShell. Установщик создаёт ярлык **IVAN100 - Запись уроков** и запуск помощника при входе в Windows. Параметр `-NoStartup` отключает создание автозапуска.
2. Открыть ярлык или <http://127.0.0.1:18765/>. В первоначальной настройке нажать **Запустить и настроить OBS**. Создаются отдельные профиль и коллекция **IVAN100 Lessons**. Если OBS уже работает с выключенным WebSocket, закрыть OBS и повторить настройку.
3. Открыть платформу в отдельном окне браузера. Выбрать её окно, окно Телемоста, микрофон и монитор. Сохранить источники. Проверить изображение и звук кнопкой **Тест · 1 минута**.
4. На платформе под учителем открыть **Запись на ПК**, получить одноразовый код и вставить его в пульт. После подключения включить **Записывать уроки через OBS** на платформе.
5. Нажать **Войти в Rutube**, войти в отдельном окне Edge помощника и включить **Загружать записи автоматически**. Пароли не вводятся в пульт. Вход в других браузерах не используется.

## Каждый урок

- Оставить окна платформы и Телемоста открытыми, не сворачивать записываемое окно. Убедиться, что пульт показывает готовность.
- Начать занятие кнопкой платформы. Помощник получает команду и начинает OBS. Открытие одного только звонка Телемоста не запускает запись.
- Для LibreOffice/Python выбрать нужное окно в пульте и нажать **Окно программы**. Кнопка **Горячие клавиши** открывает небольшую панель поверх окон: `Ctrl+Alt+1` — платформа, `2` — выбранная программа, `3` — выбранный монитор, `4` — чёрный экран и тишина.
- Закончить занятие кнопкой платформы. OBS сохраняет MKV; помощник создаёт MP4 без повторного кодирования и загружает его в Rutube с доступом **только по ссылке**. После обработки плеер появляется в материалах соответствующего урока.
- Если не завершить занятие вручную, действует предельное время платформы с запасом. Пульт соблюдает этот предел даже при потере интернета. Закрытие вкладки или окна пульта запись не останавливает.

OBS захватывает окно, а не закреплённую вкладку. Поэтому в окне платформы лучше оставить одну вкладку. Захват звука Телемоста в Chrome может захватить другие звучащие вкладки Chrome; для изоляции использовать приложение Телемоста или отдельный браузер только для звонков. В других режимах изображения микрофон и Телемост продолжают записываться. Для проверки голосов учеников нужен говорящий участник звонка.

## Если загрузка не удалась

Файлы лежат в `%USERPROFILE%\Videos\Ivan100 Lessons`, очередь — в `%USERPROFILE%\Ivan100Recorder\state.json`. Ничего автоматически не удаляется. После восстановления интернета нажать **Продолжить загрузку**. При неопределённом результате помощник проверяет уже созданный ролик, чтобы не загружать копию.

Запасной вариант: **Файл на компьютере** → вручную загрузить MP4 в Rutube с доступом **только по ссылке** → вставить полную ссылку, включая `?p=…`, в строку этой записи → **Прикрепить**. После готовности видео пульт отправит ссылку платформе.

Оставлять компьютер включённым до окончания загрузки. Изменения формы Rutube или истечение входа могут потребовать действия в пульте. Доступ «только по ссылке» позволяет смотреть видео любому, кто получил полную ссылку.

## Обслуживание

Установка: `%USERPROFILE%\Ivan100Recorder\app`. Перед обновлением дождаться окончания записи и загрузки и повторить установку. Установщик корректно закрывает незанятый помощник и переносит настройки и вход Rutube из прежнего каталога AppData при первом обновлении. Каталог вне AppData доступен также при запуске установщика из приложения MSIX. Настройки и локальные видео находятся вне каталога приложения. Фоновый запуск выполняет задача Windows **IVAN100 Lesson Recorder**, с резервным ярлыком **IVAN100 Recorder** в автозагрузке. Для отключения автоматического запуска отключить эту задачу и убрать резервный ярлык.

На сервере метаданные хранятся в `PLATFORM_DATA_DIR/desktop-recordings.json`; этот файл нужно включить в обычное резервное копирование данных. По умолчанию функция выключена для всех учителей. Устройство получает отдельный отзываемый токен, не дающий доступа к остальному API платформы.

Проверка кода из корня проекта:

```text
node --test server/desktopRecording.test.js server/desktopRecording.integration.test.js tools/lesson-recorder/engine.test.mjs
npm run build
```
