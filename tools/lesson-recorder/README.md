# Запись уроков IVAN100 на компьютере

Помощник для Windows связывает занятие на платформе с OBS Studio и Rutube. Видео остаётся на компьютере; платформа хранит только состояние обработки и закрытую ссылку. Старые записи уроков продолжают открываться прежним способом.

## Один раз настроить

1. Войти на платформу под преподавателем и открыть постоянный раздел **Запись уроков** в меню. Нажать **Скачать помощник для Windows**, распаковать ZIP через «Извлечь всё» и дважды нажать **Install.cmd**. Нужны Windows 10/11 x64 и интернет. Установщик проверит OBS Studio 28+, Node.js 22+, FFmpeg и Microsoft Edge и установит недостающие компоненты через [WinGet Microsoft](https://learn.microsoft.com/windows/package-manager/winget/). Подтвердить запросы установщиков. Если WinGet отсутствует, установить «Установщик приложений» Microsoft из Microsoft Store и повторить. Ошибка установки остаётся видна в окне; после её устранения установку можно повторить.
2. Откроется мастер в локальном пульте. В шаге **Папка** выбрать диск и папку для видео и сохранить. В списке показано свободное место. Настройка проверяет возможность записи. Никакого автоматического перехода на C при ошибке диска нет.
3. В шаге **Изображение и звук** нажать **Запустить и настроить OBS**. Создаются отдельные профиль и коллекция **IVAN100 Lessons**. Если OBS уже работает с выключенным WebSocket, закрыть OBS между уроками и повторить настройку. Открыть платформу в отдельном окне браузера с одной вкладкой. Выбрать окно платформы, окно разговора (платформа, Телемост или другое приложение), микрофон и монитор. Сохранить источники.
4. В разделе **Запись уроков** на платформе получить одноразовый код и вставить его в шаг **Платформа** в пульте. Код действует 5 минут. Подключение нового компьютера заменит прежнее: сначала дождаться завершения его загрузок. Другой преподаватель использует свой аккаунт платформы и свой Rutube, а не копию чужих настроек.
5. В шаге **Проверка** начать минутный тест. Сказать несколько слов и попросить собеседника ответить. Тест закончится сам; можно завершить раньше. Нажать **Открыть пробную запись**, прослушать её и подтвердить, что видны изображение и слышны оба голоса. При смене папки или источников проверка становится неактуальной. Тест не загружается автоматически.
6. В шаге **Rutube** нажать **Войти в свой Rutube**, войти в отдельном окне Edge помощника, вернуться и нажать **Проверить вход**. Включить **Загружать записи автоматически** и завершить мастер. Пароли вводятся только на сайте Rutube. Вход в других браузерах не используется.

Большие файлы: помощник ждёт появления закрытой ссылки и разрешения публикации
до 12 часов на каждом этапе. Не закрывайте окно Rutube. Повторное продолжение
загрузки использует уже открытый редактор этого ролика и не прерывает передачу
файла переходом на другую страницу. После публикации готовность видео проверяется
в фоне без десятиминутного предела; до готовности ссылка не выдаётся как готовая запись.
7. Вернуться на платформу в **Запись уроков** и включить **Автоматически записывать уроки**. Полная инструкция для учителя и решение проблем находятся там же. Постоянная кнопка открывает пульт в отдельной вкладке; плавающей плашки поверх урока нет.

Установщик создаёт ярлык **IVAN100 - Запись уроков** и запуск при входе в Windows. Для ручного обслуживания: `install.ps1 -SetupDependencies -OpenPanel`; `-NoStartup` пропускает создание автозапуска, `dependencies.ps1 -CheckOnly` проверяет компоненты без установки. В архиве только файлы приложения — без настроек, токенов, видео и профиля Rutube.

## Каждый урок

- Оставить окна платформы и Телемоста открытыми, не сворачивать записываемое окно. Убедиться, что пульт показывает готовность.
- Начать занятие кнопкой платформы. Помощник получает команду и начинает OBS. Открытие одного только звонка Телемоста не запускает запись.
- Для LibreOffice/Python выбрать нужное окно в пульте и нажать **Окно программы**. Кнопка **Горячие клавиши** открывает небольшую панель поверх окон: `Ctrl+Alt+1` — платформа, `2` — выбранная программа, `3` — выбранный монитор, `4` — чёрный экран и тишина.
- Закончить занятие кнопкой платформы. OBS сохраняет MKV; помощник создаёт MP4 без повторного кодирования и загружает его в Rutube с доступом **только по ссылке**. После обработки плеер появляется в материалах соответствующего урока.
- Между последовательными занятиями кнопки OBS нажимать не нужно: завершить урок на платформе и начать следующий. При потере связи запись остаётся активной до 5 минут на переподключение, в том же файле; возврат в звонок отменяет отложенную остановку. Без возврата звонка запись остановится через 5 минут. Явное завершение занятия и предельное время записи действуют сразу. Следующий урок получает отдельный файл, загрузка предыдущего выполняется независимо.
- **Начать вручную** — запасной локальный режим без автоматической привязки к уроку. Его нужно завершать кнопкой пульта; максимальная длительность — пять часов. Для обычных уроков используйте автоматический запуск с платформы.
- Если не завершить занятие вручную, действует предельное время платформы с запасом. Пульт соблюдает этот предел даже при потере интернета. Закрытие вкладки или окна пульта запись не останавливает.

OBS захватывает окно, а не закреплённую вкладку. Поэтому в окне платформы лучше оставить одну вкладку. Захват звука Телемоста в Chrome может захватить другие звучащие вкладки Chrome; для изоляции использовать приложение Телемоста или отдельный браузер только для звонков. В других режимах изображения микрофон и Телемост продолжают записываться. Для проверки голосов учеников нужен говорящий участник звонка.

## Если загрузка не удалась

Папка файлов указана внизу пульта. На компьютере Ивана используется `D:\Видео\Ivan100 Lessons`: туда сохраняются и исходные MKV, и MP4 для Rutube. Очередь — в `%USERPROFILE%\Ivan100Recorder\state.json`. Ничего автоматически не удаляется. После восстановления интернета нажать **Продолжить загрузку**. При неопределённом результате помощник проверяет уже созданный ролик, чтобы не загружать копию.

Запасной вариант: **Файл на компьютере** → вручную загрузить MP4 в Rutube с доступом **только по ссылке** → вставить полную ссылку, включая `?p=…`, в строку этой записи → **Прикрепить**. После готовности видео пульт отправит ссылку платформе.

Оставлять компьютер включённым до окончания загрузки. Изменения формы Rutube или истечение входа могут потребовать действия в пульте. Доступ «только по ссылке» позволяет смотреть видео любому, кто получил полную ссылку.

## Обслуживание

Установка: `%USERPROFILE%\Ivan100Recorder\app`. Перед обновлением дождаться окончания записи и загрузки и повторить установку. Установщик корректно закрывает незанятый помощник и переносит настройки и вход Rutube из прежнего каталога AppData при первом обновлении. Каталог вне AppData доступен также при запуске установщика из приложения MSIX. Настройки и локальные видео находятся вне каталога приложения. Фоновый запуск выполняет задача Windows **IVAN100 Lesson Recorder**, с резервным ярлыком **IVAN100 Recorder** в автозагрузке. Для отключения автоматического запуска отключить эту задачу и убрать резервный ярлык.

На сервере метаданные хранятся в `PLATFORM_DATA_DIR/desktop-recordings.json`; этот файл нужно включить в обычное резервное копирование данных. По умолчанию функция выключена для всех учителей. Устройство получает отдельный отзываемый токен, не дающий доступа к остальному API платформы.

Папка видео выбирается в мастере и сохраняется в `config.recordDirectory` при обновлении. У новой установки без выбранной папки запись недоступна. OBS получает выбранную папку перед каждой записью; временный MP4 создаётся рядом с исходным MKV. Изменить папку можно только вне записи и загрузки. Старые файлы и пути в очереди сохраняются; переносить или редактировать их вручную для смены папки не нужно. На компьютере Ивана остаётся `D:\Видео\Ivan100 Lessons`.

Проверка кода из корня проекта:

```text
node --test server/desktopRecording.test.js server/desktopRecording.integration.test.js tools/lesson-recorder/engine.test.mjs
npm run build
```
