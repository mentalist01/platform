# Видеоредактор, связанный с записью уроков Python

Пользователь 7 октября 2026 определил конечную цель: постепенно развивать полноценный редактор внутри пульта. Запись идёт параллельно монтажу, дубли последовательно добавляются в ленту; учитель редактирует завершённые фрагменты и одной кнопкой выкладывает готовый урок в выбранную тему «Изучения Python». Агент самостоятельно исследует функции, реализует их и проверяет код, настоящую сборку видео и интерфейс. Пользователь продолжает работу сообщением «продолжи», без необходимости каждый раз придумывать следующую функцию.

## Принципы

- Исходники не перезаписываются и не удаляются монтажными действиями. Проект хранит решения о монтаже; экспорт — отдельный файл.
- Учитель явно подтверждает публикацию после просмотра. Запись не становится учебным материалом до нажатия «Выложить в изучение Python».
- Новая студия не меняет обычные уроки, групповые записи или разборы пробников. Старые Python jobs без монтажного проекта сохраняют прежнее поведение.
- Сначала функции для объяснения программирования: быстрые дубли, точные разрезы, текст, выделение важных областей, звук. Сложные эффекты добавляются после устойчивой базы.
- Ошибка рендера, перезапуск пульта или потеря сети не должны уничтожать исходники/монтаж или публиковать черновик.
- Локальные испытания используют вымышленные проекты. Реальные материалы и занятия не создаются ради QA. Установка/перезапуск — только после server preflight и локального idle.

## Исследование

Официальные источники, прочитанные 7 октября:

- [CapCut: основные действия с клипами](https://www.capcut.com/resource/how-to-use-capcut): выбор клипа, разделение, удаление, маркеры, преобразования.
- [CapCut: разрез по позиции курсора](https://www.capcut.com/resource/split-video-into-parts): лента, позиция воспроизведения, самостоятельная правка полученных частей.
- [Adobe: ripple editing](https://helpx.adobe.com/uk/premiere/desktop/edit-projects/trim-clips/perform-ripple-edits.html): изменение границ с автоматическим закрытием промежутка и обновлением длительности.
- [FFmpeg filters](https://www.ffmpeg.org/ffmpeg-filters.html): trim/atrim, временные метки и concat. Для первого этапа короткие части перекодируются отдельно, затем объединяются: память ограничена и произвольная перестановка не требует буферизовать часы исходника. Временный звук PCM, финальный AAC кодируется один раз, чтобы не добавлять задержку кодека на каждом стыке.

Настоящий интерфейс проверен на вымышленных данных, включая окно 390 px и перезагрузку черновика. Публикация, установка и проверка на настоящем OBS ждут успешного серверного preflight: сейчас другая запись блокирует работы на сервере. Детали проверки: output/python-editor-qa/report.md.

В работе: проект в состоянии job, отметки границ по подтверждённым паузам OBS, отдельные завершаемые дубли, восстановление хвоста по ffprobe, автоматическое сохранение. Лента с масштабом, выбором и меню правой кнопки. Просмотр отдельной части/монтажа, разделение, обрезка, удаление с закрытием промежутка, копирование, перемещение, объединение соседних непрерывных частей, отмена и пересъёмка последнего дубля. Экспорт выбранных диапазонов в MP4 и существующая привязка к теме/подразделу Python.

Критерии готовности: unit/API сценарии; цветные и звуковые ffmpeg fixtures для точности реальных кадров, длительности и аудио; UI сценарии записи/паузы/разреза/удаления/undo/перезагрузки; узкое окно; отсутствие автоматической публикации; неизменность обычных уроков. Ограничение первого этапа: один исходник и одна объединённая дорожка изображения+микрофона, до 300 монтажных фрагментов, 30 отмен. Редактирование параметров цвета/слоёв и многодорожечная композиция — следующие этапы.

## Следующие этапы

### Второй этап — управление лентой, 1.5.1

Подготовлен 7 октября поверх первого этапа, оба пока ждут установки: серверный preflight и локальный пульт показывают активную запись. Добавлены общий курсор/воспроизведение, геометрически точное попадание в короткие клипы, перетаскивание в произвольное место, предварительный контур обрезки за края, привязка к стыку/курсору с Alt для обхода, S и покадровые стрелки, подбор масштаба «Вся лента». Миниатюры настоящих кадров появляются после подготовки предпросмотра, ограничены 32 за просмотр/128 в кэше. Redo с устойчивой историей сохраняет новые дубли через undo/redo и перезагрузку. Старые проекты без future совместимы.

Исследованы [привязка Adobe Premiere](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/snap-clips.html) и [монтажные инструменты DaVinci Resolve](https://www.blackmagicdesign.com/sg/products/davinciresolve/edit/). В нашей ленте перестановка закрывает промежутки автоматически, обрезка пока только сокращает существующий диапазон. Строго проверяется ревизия на момент начала жеста; отмена/потеря захвата не пишет изменения.

179 проверок прошли, включая новую математику курсора, сериализацию redo с новыми дублями, атомарность перестановки и API. UI: перенос первого клипа в конец, Ctrl+Z/Shift+Z, разрез S по общему курсору, обрезка мышью, просмотр итогового MP4 11.01 s без ошибки декодера, миниатюры у всех трёх тестовых клипов, курсор дошёл до конца вместе с видео. Ширина 390 px: горизонтального переполнения нет, PageDown доводит до ленты; кнопка публикации целиком внутри viewport. Отчёт output/python-editor-151-qa/report.md.

3. Несколько дорожек, блокировка/скрытие/mute, отдельная громкость и fade, скорость, кадрирование/масштаб, текст и стрелки, простые переходы. Проверка предпросмотра и итогового файла для каждого преобразования.
