# Исправление тестов Python

В рабочем банке обнаружены 24 задачи из тем 101–106, у которых ожидаемый
ответ заполнен, а `input` пуст. Это повреждение сохранённых данных, а не
только отображения: сервер передавал Python именно пустую строку.
Исторический способ появления этих записей не установлен.

Дополнительно импорт и сохранение тестов в интерфейсе вызывали `trimEnd()`.
Из-за этого терялись значимые пробелы разделителя и последняя пустая строка.
В исходном тесте «Свой разделитель» также отсутствовала четвёртая пустая
строка. В примере «Фильтр по длине» исправлен счётчик: из слов «дом»,
«машина», «код», «цикл» длину от пяти символов имеет одно слово.

## Применение

`pythonCoreCurriculaMigration` при чтении общего и преподавательских банков
применяет точечные исправления из `pythonIoTestData` и
`pythonCurriculumTestData`. Сопоставляются известные ID, названия и старые
значения тестов; пользовательские правки и дополнительные тесты сохраняются.
Повторное применение ничего не меняет. Версия всей учебной программы не
повышается: задания и прогресс учеников не пересоздаются.

Перед выпуском сохранить резервную копию каталога данных. После обновления
сервера открыть банк задач и проверить, что исправленные входные данные
сохранены. Откат кода сам по себе не возвращает прежние повреждённые тесты.

## Проверка

`node --test server/pythonCoreCurriculaMigration.test.js server/pythonForCurriculumMigration.test.js server/pythonCurriculumRepairs.test.js server/pythonRunnerSource.test.js server/pythonSandbox.test.js server/pythonCurriculum.integration.test.js src/utils/pythonTestData.test.js`

Для полного аудита нужен JSON банка задач с полями версии учебных программ:

`node scripts/audit-python-curriculum.mjs bank.json --repair --include-infinite`

Аудит запускает независимые решения через тот же Python runner и запуск
песочницы, которые использует сервер. Проверяются все тесты каждой задачи,
а для каждой задачи — отклонение заведомо неверного ответа. Отдельный
интеграционный тест поднимает сервер с временной БД и проходит авторизацию
ученика, чтение исправленного банка, отправку решений и сохранение прогресса
для 25 затронутых задач через HTTP API. Рабочие данные он не использует.

`sys.stdin` теперь доступен через ограниченный объект с копией входа в памяти.
Реальный модуль `sys`, файловые дескрипторы, процессы и сеть не раскрываются.
Сохраняются изоляция Linux, ограничения времени, памяти и объёма вывода.
Windows запускает интерпретатор в UTF-8 для проверки русскоязычных заданий.
Два теста изоляции Linux на Windows пропускаются и должны запускаться на Linux.
Алгоритм сравнения ответов не изменён.

Результат локального полного прогона 26 сентября 2026 года: 1186 задач
(186 из рабочего банка и 1000 из бесконечной тренировки), 3734 теста
правильных решений пройдены, 1186 заведомо неверных решений отклонены,
задач без эталонного решения для аудита нет. Сборка интерфейса и отдельная
проверка 25 исправленных задач через API ученика также прошли. Это результат
локальной проверки; проверка установленного выпуска на сервере выполняется
отдельно после развёртывания.
