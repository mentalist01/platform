# Достижения IVAN100: первая версия

Цель — сделать подготовку к ЕГЭ похожей на личное прохождение игры: показать ученику конкретные шаги роста, а не сравнивать его с более сильными учениками.

## Что внедрено

132 постоянные награды. Коллекция ученика доступна в меню «Достижения». Категории, поиск, фильтры «Получены / Впереди», три ближайшие цели со шкалами, четыре ступени оформления: бронза, серебро, золото, алмаз. Цвет показывает ступень награды, а не статистическую редкость среди пользователей.

Уведомление появляется внизу справа на 6,5 секунды. Собственный тихий трёхнотный звук синтезируется на устройстве; звук можно отключить. Есть кнопка проверки оформления и звука без выдачи настоящей награды. Несколько одновременных наград группируются, чтобы не перекрывать работу. Во время звонка, доски и совместного кода опрос и уведомления откладываются. Поддерживаются мобильный экран, тёмная тема, клавиатура, aria-live и уменьшение анимации.

## Правила честности и мотивации

- Источник — сохранённые проверенные решения, завершённые пробники и подтверждённые награды за домашку. Входы, клики, сохранение кода и проценты, выставленные вручную, не считаются решением.
- Повторное решение одной задачи не увеличивает число уникальных решений. Три попытки одного пробника считаются одним пробником. Рост балла оценивается на следующем отдельном пробнике относительно первого завершённого.
- За ошибки сами по себе наград нет: награда за исправление требует успешного решения после ошибки, один раз на задачу. Нет наград за ночные занятия, сидение на сайте, покупку тарифа, превосходство над другим учеником или бесконечное число неудачных попыток.
- Награда не отнимается за перерыв или изменение каталога задач. Серии используют уже существующие правила платформы; отдельно есть накопительные дни с перерывами.
- Python не превращается в оценку: достижения требуют решений, а нейтральные 100% за отсутствие заданий ЕГЭ не являются доказательством выполнения домашки.
- Прошлый прогресс учтён при первом открытии тихо. Такие награды явно подписаны «Учтено из прошлого прогресса», без выдуманных дат получения.
- Нет дополнительных XP, монет, штрафов или изменений тарифа: игровая экономика сохранена.

## Надёжность

Сервер проверяет условия. Отдельный файл достижений на ученика хранит постоянные награды и факт доставки уведомлений. Имена файлов хешированы, путь не строится из пользовательского ввода. Чтение коллекции не переписывает прогресс, оплаты, домашку или XP. Запись атомарная; выдача при успешном решении использует состояние до и после действия, поэтому первая ачивка не теряется, даже если коллекцию ещё не открывали. Ошибка необязательной награды не отменяет сохранённое решение.

Опрос раз в минуту только в видимой вкладке, немедленное обновление после подтверждённого решения/завершения пробника, пауза во время рабочего экрана урока. Сервер отдаёт только собственные достижения; преподаватель может читать достижения своего ученика, но не перехватывать его уведомления. Получение уведомлений однократное между вкладками. Если вкладка закрылась после получения, награда останется в коллекции, даже если уведомление не успело отобразиться.

## Что можно развивать дальше

1. Выбор трёх любимых наград для публичного профиля, с настройкой приватности.
2. Небольшие сезонные главы подготовки и персональные квесты, согласованные с преподавателем.
3. Уникальные титулы и косметические рамки за большие серии; бонусы XP — отдельным решением после проверки баланса.
4. Новые награды за дополнительные темы Python и конкретные учебные сценарии по мере появления достоверной истории этих действий.

Ни одна из этих идей не включена скрыто в первую версию.
