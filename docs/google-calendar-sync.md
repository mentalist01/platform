# Обновление Google Calendar

Кнопка «Обновить» в общем календаре и кнопка обновления в настройках Google
вызывают `/api/teacher-calendar-sync/refresh` с `force: true`, затем перечитывают
расписание. Обычный `GET /api/teacher-schedule` использует серверный кэш.
Открытый календарь проверяет обновления каждые пять минут и при возвращении
на вкладку. Ручное обновление обходит кэш; несколько одновременных ручных
запросов объединяются. Если уже идёт фоновая загрузка, после неё выполняется
свежая ручная загрузка, даже когда фоновая завершилась ошибкой.

Если для календаря из iCal-ссылки есть действующее OAuth-подключение, события
читаются через Google Calendar API, с раскрытием повторений и пагинацией.
ID календаря должен совпадать с подключённым или присутствовать в списке
доступных календарей. Выбор другого календаря для отправки отмен не меняет
источник импортируемого расписания. Прошлые занятия сохраняются в выборке
для истории и финансов. Идентификаторы занятий по iCalUID и времени начала
остаются совместимыми с прежним импортом.

Без такого подключения продолжает работать импорт iCal. Ручной запрос
не отправляет условные `If-None-Match` / `If-Modified-Since` и требует
перепроверки HTTP-кэша. Однако платформа не управляет временем публикации
самого iCal-файла у его владельца.

При ошибке ручного обновления сервер возвращает ошибку, не подменяя её
успехом со старыми данными. `lastFetchedAt` меняется только после успешного
получения календаря; интерфейс показывает время проверки и ошибку над сеткой.

```sh

```
