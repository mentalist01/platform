# Call Panel Client UX Notes

## Goal

Сделать панель звонка более спокойной, понятной и клиент-ориентированной:

- пользователь сразу понимает, что происходит;
- главное действие считывается без угадывания;
- пустые и ожидательные состояния не выглядят как ошибка системы;
- технические статусы переводятся на человеческий язык.

## Safe Changes Already Applied

В `src/components/CallSection.jsx` уже внесены безопасные UX-правки без изменения структуры экрана:

- статус подключения переписан на более понятные формулировки;
- пустое состояние до входа в звонок стало объяснять следующий шаг;
- индикатор качества связи больше не показывает сухое `нет данных`;
- CTA подключения получил более понятный tooltip/aria label;
- пустое состояние чата стало мягче и дружелюбнее.

## Current UX Gaps

1. Главный CTA остаётся иконкой без видимой подписи.
2. Центральная зона слишком декоративная для предзвонкового сценария.
3. Пользователь не видит явную готовность устройств до входа.
4. Чат визуально живёт отдельно от основного сценария звонка.
5. Верхняя панель не даёт контекст урока: кто, какой урок, сколько времени.

## Recommended Next Step

Собрать предзвонковый сценарий вокруг одной карточки:

- заголовок: `Вы готовы к уроку?`
- подзаголовок: `Проверьте устройства и войдите в звонок, когда будете готовы.`
- блоки статуса:
  - `Микрофон: работает`
  - `Камера: работает`
  - `Связь: хорошая`
- действия:
  - `Войти в урок`
  - `Проверить камеру и микрофон`

## Suggested Layout

1. Верхний header:
   - предмет или формат занятия;
   - имя второй стороны;
   - таймер урока или статус начала;
   - статус собеседника.

2. Центральная область:
   - превью собственной камеры;
   - справа статусы готовности;
   - основной CTA входа.

3. Нижняя control bar:
   - `Микрофон`
   - `Камера`
   - `Экран`
   - `Чат`
   - `Ещё`
   - отдельно справа `Завершить`

4. Чат:
   - встроить в правую колонку или сделать частью control bar;
   - показывать счётчик как часть основного сценария.

1. Видимая подпись у основной кнопки подключения.
2. Предзвонковая карточка готовности устройств.
3. Более полезный header с контекстом урока.
4. Встраивание чата в основную композицию.
5. Упрощение декоративного фона в зоне звонка.
