# Обмен подготовленными наборами

В «Заданиях к уроку» у каждого своего набора есть «Поделиться». Автор выбирает конкретных преподавателей и сохраняет доступ. В «Доступных мне» получатель видит опубликованные ему наборы, автора, номер и часть; открывает условия, эталоны и вложения и нажимает «Добавить себе копию».

Публикация — снимок сохранённого полного набора. Автосохранённый незавершённый черновик не подменяет опубликованную версию. Передать новую версию можно повторным сохранением доступа. Снятие всех отметок закрывает просмотр, в том числе если свой набор сейчас является черновиком. Публикация использует версию доступа: устаревшее окно не отменит более новые изменения.

Копия имеет собственные ID набора, задач и логических вложений. Условия, ответы, число полей, независимая проверка вопросов, сложность, имена файлов в Python и флаги подключения сохраняются. Приватные ID файлов из конспектов автора в копию и предпросмотр не передаются. Неизменяемые байты вложений безопасно переиспользуются; право владения логическими вложениями принадлежит получателю. Правки и обрезка изображения в копии не изменяют оригинал. Учебные прохождения и решения учеников не копируются.

Повторный запрос копирования одной опубликованной версии возвращает прежнюю копию; даже после её редактирования и перезапуска сервера дубликата и перезаписи не происходит. Новую опубликованную версию можно взять отдельной копией. Отзыв доступа не удаляет уже полученные копии.

Список преподавателей содержит только ID и имя. Ученики, невыбранные преподаватели и удалённые аккаунты не получают содержимое. Маршрут файлов проверяет принадлежность файла конкретному опубликованному набору; общий маршрут приватных вложений не расширен. Все ответы имеют `private, no-store`. Изменения доступа и копирование используют общую блокировку хранилища и атомарный файл `state.json`; при ошибке записи откатывается изменение памяти. Ни один существующий набор не публикуется автоматически.

Проверки: модульные сценарии публикации, черновика, изоляции, отзыва, конфликтов версий, новых публикаций, перезапуска, независимого редактирования, повторных запросов, отсутствующего файла и точного сохранения байтов. HTTP-сценарий двух авторизованных преподавателей и ученика проверяет изображения, приватность, копию и чтение её `17_2.txt` реальным Python.
