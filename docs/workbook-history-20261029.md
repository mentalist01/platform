# Workbook attempts and saved versions

Prepared lesson attachments already keep an immutable source asset. Before this change, both ordinary and live helpers always seeded from `card.solutions[assetId]`, and each successful save replaced that solution's metadata. Content-addressed bytes survived, but there was no per-document version index or original-file restart action.

The board now labels the original download explicitly and offers saved-version history, dated and attributed to the authenticated saver. A separate durable JSONL journal indexes versions per run/card/asset; it contains metadata only and references the existing content-addressed file bytes. Unchanged files within the same attempt are deduplicated. History loads on request, 30 entries at a time, and is absent from regular board updates except for its count. A bounded document cache avoids repeatedly parsing active histories. An existing current save is represented lazily and archived before it can be replaced. Older unindexed overwritten versions cannot reliably be assigned to a task automatically.

Starting over requires explicit confirmation that everyone has saved and closed the workbook, an exact current file revision and attempt ID, and existing board write permission. Group pupils can read/download history but cannot restart. Homework seeds keep their own attempt numbering; restarting from this new action is limited to lesson boards. Unsaved live edits block restart.

The reset keeps the canonical last saved file and its Notes link available while selecting the immutable original (or blank ODS plus original text) for the next helper opening. New live epochs and ordinary writer keys fence out old helpers and unexchanged old tickets. Saves in the new attempt continue the monotonically increasing canonical revision and retain the same Notes file identity. Answer status and lesson achievement credit do not reset.

Validation covers ordinary and live/fallback saves, identical-file deduplication, exact old-version downloads, original preservation, legacy metadata, torn journal tails, durable reload, unauthorized access, shared unsaved changes, stale grants/tickets, continuing Notes links, group read-only behavior, text inputs with blank ODS, pagination and histories after removing a set. Browser QA exercises the real card and new dialogs against an isolated authenticated backend. The installed helper protocol is unchanged.
