# Диагностика нагрузки во время реального урока

Сборщик работает отдельно от сайта и не требует перезапуска PM2. Он сохраняет только технические показатели: CPU и RAM процессов Node, TURN, Python и nginx, общую нагрузку Linux, сетевой трафик и обезличенные события длительности сохранения записи урока.

Он **не записывает** звук, видео, экран, доску, сообщения, URL, IP-адреса, переменные окружения, ключи или командные строки процессов.

## До урока

После доставки этих файлов на сервер откройте SSH-терминал Timeweb, перейдите в папку проекта и запустите сбор на 180 минут:

```bash
cd /root/platform
npm run diagnostics:lesson -- start 180
```

Если проект расположен в другой папке, замените `/root/platform` на неё. После сообщения `Diagnostics started` SSH можно закрыть. Сайт и PM2 перезапускать не нужно.

Начните сбор за 5–10 минут до звонка, чтобы в отчёте был виден спокойный фон сервера.

## Во время урока

Проводите обычный урок. Ничего нажимать в терминале не нужно. Полезно отдельно записать приблизительное московское время для трёх моментов:

- начало звонка;
- включение демонстрации экрана или камеры;
- окончание звонка.

Это не обязательно, но поможет сопоставить скачки нагрузки с действиями на уроке.

## После урока

Снова откройте SSH, перейдите в проект и остановите сбор:

```bash
cd /root/platform
npm run diagnostics:lesson -- stop
```

Команда дождётся создания архива и напечатает строку вида:

```text
DIAGNOSTIC_FILE=/root/platform/diagnostics-output/lesson-diagnostics-20260820T120000Z.json.gz
```

Если 180 минут уже истекли, сборщик завершится сам; команда `stop` всё равно покажет последний архив. Проверить состояние можно командой:

```bash
npm run diagnostics:lesson -- status
```

## Как передать отчёт

Скачайте напечатанный файл `.json.gz` через файловый менеджер Timeweb и прикрепите его к сообщению в Codex. Вместе с файлом напишите примерное время начала и конца звонка и использовались ли камера, демонстрация экрана и доска.

Не присылайте `.env`, конфигурацию TURN, пароли, SSH-ключи или полный PM2-лог — они для этой диагностики не нужны.
