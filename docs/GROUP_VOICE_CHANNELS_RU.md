# Голосовые каналы групповых занятий

Размер группы не ограничен настройкой вместимости. Проверен состав из 20 учеников; для каждого участника занятия автоматически создаётся отдельный канал.

## Как провести занятие

1. Откройте «Мини-группы → Занятия → Голосовые каналы» или занятие из календаря.
2. Для общего разбора войдите в «Общий канал». Микрофон включается после входа и разрешения браузера; камера выключена по умолчанию.
3. Для самостоятельной работы преподаватель нажимает «Распределить по каналам»: подключённые ученики автоматически переходят в каналы со своими именами. Можно также переходить вручную. Они создаются автоматически по составу занятия: шесть учеников — шесть отдельных каналов и один общий.
4. Преподаватель входит к нужному ученику. Ученик нажимает «Показать экран» и выбирает окно LibreOffice. Звук, камера и экран доступны участникам выбранного канала.
5. Для работы в парах преподаватель может создать дополнительный канал. Дополнительные каналы сохраняются у группы для следующих занятий.
6. Кнопка «Собрать в общий» автоматически переводит подключённых учеников и преподавателя в общий канал. Выключенный микрофон остаётся выключенным. Ученики, не подключённые к голосу, не подключаются автоматически.

При открытии доски или редактора связь сохраняется; внизу появляется панель возврата к каналам. Доска и редактор остаются общими для занятия. При переходе между голосовыми каналами прежняя демонстрация экрана и камера останавливаются — в новом канале их нужно включить снова.

Канал с именем ученика доступен всем участникам занятия: это место работы, а не закрытая личная комната. Можно находиться только в одном голосовом канале данного занятия, в том числе при открытии нескольких вкладок.

В голосовые каналы запланированного или активного занятия можно входить заранее: проверка времени входа снята. Завершение или отмена занятия и исключение ученика из группы закрывают соответствующий доступ. Существующее автоматическое завершение занятия через 30 минут после назначенного конца пока сохраняется; постоянные каналы группы независимо от занятий — отдельный сценарий. Запись при нативном групповом звонке не запускается. Ссылка Телемоста необязательна и остаётся резервным вариантом с прежним отдельным сценарием записи.

## Настройка и проверка

`LEARNING_GROUPS_ENABLED=1` и `LEARNING_GROUP_RTC_ENABLED=1` включают группы и нативные голосовые каналы. Пример окружения и конфигурация PM2 обновлены. Для публикации нужны обычная сборка клиента и перезапуск сервера; уже заданное в окружении значение `LEARNING_GROUP_RTC_ENABLED=0` нужно изменить отдельно.

Проверены API и WebSocket: состав из 20 учеников, изоляция каналов, переходы, создание каналов, автоматическое распределение и сбор, вход со второй вкладки, исключение ученика, запрет раннего входа и закрытие занятия. В браузере проверены независимые сессии преподавателя и учеников с тестовыми микрофонами и настоящими WebRTC-соединениями, передача искусственного видео вместо экрана, сохранение связи при открытии доски и выключенного микрофона после автоматического переключения. Отдельно проверяется путь через основной интерфейс платформы.

Это локальные функциональные проверки, не нагрузочное испытание сервера или соединений через интернет. Текущая реализация передаёт медиа между браузерами отдельно для каждого собеседника; TURN, если используется, ретранслирует трафик. Вместимость группы в 20 учеников не означает проверенную работу 21 одновременной камеры или демонстрации. Для реального пилота проверяйте общий голосовой канал и одну демонстрацию экрана, затем переходы преподавателя между отдельными каналами. Мощность процессора сама по себе не определяет качество связи.
