# Достижения за задачи на уроках

16 новых наград в категории «На уроке», всего 148. Каталог и суммы XP находятся в `src/data/achievementCatalog.js`. Для цепочки количества решений действует накопительный потолок: 150 / 600 / 1500 / 3000 / 6000 XP за 1 / 10 / 50 / 100 / 250 задач. При переходе начисляется разница.

## Сложность и темы

В редакторе задачи есть отдельная отметка «Сложная задача», изначально выключенная. Настройки сложности для целого набора нет. Позиция, номер ЕГЭ, название и сложность предыдущей задачи не включают отметку автоматически. Открытый урок хранит снимок задачи; изменение набора не меняет сложность прошлых решений.

Тема для этих правил — сочетание номера ЕГЭ и части. Разнообразие направлений считается по номеру ЕГЭ. «Архитектор алгоритмов» требует по три уникальных решения в восьми разных частях №26.

## Источник результатов

После финальной успешной проверки всех обязательных ответов сервер сохраняет в карточке квитанцию: идентичность задачи и содержания, номер, часть, сложность, время, урок и присутствовавшие ученики. В группе один общий ответ даёт совместное решение всем присутствующим. Присутствие определяется по авторизованным подключениям к доске, коду и индексу страниц того же рабочего пространства. Открытый архив завершённого урока не считается присутствием. При проверке учеником нужен подключённый преподаватель; при проверке преподавателем нужны подключённые ученики.

Старые решённые карточки без такой квитанции не получают выдуманные даты или участников. История начинается после обновления. Счётчик не меняют частичные ответы, неверные попытки, просмотр, сохранение кода, переходы или ручные проценты успеваемости.

Отдельный серверный журнал `lesson-achievements/<sha256(studentId)>.json` хранит первые уникальные решения ученика. Повторные решения того же ID либо копии идентичного условия с теми же исходными файлами не увеличивают счётчик. Журнал не читается из клиентского прогресса и не изменяет обычную историю ЕГЭ/Python. Сбой награды не отменяет правильный ответ: квитанция остаётся с признаком ожидания, восстановление повторяет идемпотентную выдачу.

Уроки связываются с подходящим занятием расписания. Для занятий вне расписания страницы и наборы объединяются в период работы одного рабочего пространства; новый московский день либо 90 минут без решений начинают следующий период. Поэтому две внеплановые встречи одного ученика подряд без перерыва могут учитываться одним занятием. Возврат к пропущенной задаче требует другого московского учебного дня.

## Дополнительные доказательства

После решения преподаватель раскрывает «Учёт решения» и подтверждает самостоятельность конкретного ученика. В группе подтверждение доступно только ученикам из квитанции присутствия. Ученикам список подтверждений и личностей других участников не передаётся. «Теперь самостоятельно» требует другой, ранее совместно разобранной задачи того же номера и части.

«Повелитель файлов» учитывает задачи с прикреплённым входным txt/csv/tsv/dat, включённым для Python; наличие файла не означает проверку выполнения конкретного кода. «Таблицы слушаются» требует и решения задачи, и сохранённой таблицы через endpoint помощника; обычная загрузка файла не даёт этого доказательства. В группе учитывается сохранение преподавателя. Ctrl+S после проверки дополняет существующее решение, не создавая второе.

Старые достижения и XP не меняются. Новые награды используют существующий атомарный учёт опыта и постоянные уведомления. Во время урока уведомления по-прежнему отложены.
