# Карточки ЕГЭ: безопасная перенумерация

В кабинете преподавателя: **Успеваемость → Управление карточками**. Шестерёнка на отдельной карточке сразу открывает её банк вопросов в разделе преподавателя.

- Выпадающий номер переносит карточку на свободное место; если номер занят, две карточки меняются местами.
- Корзина убирает карточку из активного каталога. Сохранение требует подтверждения; данные архивируются, а не удаляются.
- Новая карточка добавляется на первый свободный номер. Затем её можно переместить.
- Архив позволяет восстановить карточку на свободное место вместе с прежним банком заданий и прогрессом.
- Обычное сохранение изменяет каталог только этого преподавателя и его учеников. Объединённая карточка 19–21 защищена от удаления/переноса из-за специального формата ответов и пробников.
- Только владелец платформы видит флажок применения каталога или банка вопросов ко всем преподавателям. На сервере право проверяется повторно: скрыть/подделать кнопку недостаточно.

Владелец задаётся переменной `PLATFORM_OWNER_TEACHER_ID`. Если она не задана, владельцем считается первый преподаватель в `teachers.json`. На рабочем сервере лучше задать идентификатор явно.

## Контракт данных

`taskNumber` и клиентские `number`/`id` — постоянные внутренние идентификаторы банка. Они **никогда не перенумеровываются**.

`slotNumber` — текущий номер в ЕГЭ, `displayNumber` — его подпись. В файле `task-catalog.json` поле `tasks[].number` хранит слот; `tasks[].taskNumber` хранит идентификатор. Нельзя отправлять видимый номер вместо идентификатора в API домашних работ, решений или вопросов.

Пример: внутренняя карточка 13 переезжает в слот 10. Её вопросы остаются в `tests[13]`, домашки — с `taskNumber: 13`, прогресс и история — под прежними ключами. Новая карточка в слоте 23 получает новый внутренний идентификатор (начиная с 28). Идентификаторы архивных карточек не переиспользуются. Диапазон 100+ занят Python; для новых карточек ЕГЭ зарезервированы 28–99.

Операция каталога не переписывает `progress.json`, домашки, историю ответов, заметки или файлы. XP прежних карточек фиксирован и не меняется при переносе. Выданная домашка открывает в том числе архивную карточку. Новый пустой банк не содержит старых ответов другой темы.

Общий исходный каталог хранится в `task-catalog.json`, общий банк — в `tests.json`. Личные каталоги и переопределения отдельных тем хранятся в `teacher-task-content.json`. Неизменённые темы не копируются: преподаватель продолжает наследовать их из общей базы. Поэтому изменение одной темы не отделяет от общей базы все остальные темы.

Общий режим намеренно заменяет выбранные общие темы у всех преподавателей. При общем изменении каталога личные карточки, которых нет в новом общем каталоге, переносятся в личный архив, а их банки остаются на месте — старые домашки и история не теряются. Новые внутренние идентификаторы распределяются централизованно между всеми преподавателями, поэтому личные карточки не могут получить одинаковый ключ.

Генератор **новых** персональных пробников сопоставляет слот ЕГЭ с внутренним банком через активный каталог. Уже созданные пробники и их попытки не переписываются. При отсутствии банка/вопросов для слота генерация сообщает о нехватке, а не подставляет архивные задания.

PUT `/api/task-catalog` доступен только преподавателю/администратору и требует ревизию, прочитанную при открытии редактора. Устаревшие изменения отклоняются с 409. Сохранение банка из старой вкладки сохраняет отсутствующие в её снимке новые/архивные банки.

## Проверки

`node --test server/classicTaskCatalogMutation.test.js server/classicTaskCatalog.integration.test.js server/teacherTaskContent.test.js server/teacherTaskContent.integration.test.js server/randomMockExam.test.js`

Интеграционный тест использует отдельную временную базу: перенумерация, архив, новый банк, перезапуск сервера, неизменность данных ученика после изменения каталога, выдача новой домашки, неверный/верный ответ, XP и просмотр истории преподавателем. Рабочие данные тесты не используют.

Сохранять резервные копии нужно для всей директории данных, включая `task-catalog.json` и `teacher-task-content.json`. При откате к версии без поддержки личных каталогов нельзя оставлять изменённые данные без совместимого кода.
