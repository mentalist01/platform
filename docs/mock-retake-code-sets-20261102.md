# Повторные попытки и вкладки наборов

При запуске повторной попытки сервер переносит собственные принятые ответы ученика только из предыдущей попытки и только для неизменившихся заданий. Неверные и пропущенные ответы очищаются. Сохраняются составные ответы, пустые допустимые поля и одобрение преподавателя. Новые результаты таймерной попытки скрыты до завершения; видны только уже зачтённые задания. Перенесённые ответы защищены от стирания очередным сохранением. История попыток и существующие правила наград/лимитов сохраняются. Уже открытые попытки не переписываются.

В нативный каталог кода добавлены источник набора и индекс задачи. Восстановление старой доски обновляет только эти метаданные, сохраняя код, файлы, имена, удалённые вкладки и ручной порядок внутри набора. Вкладки одного набора выводятся единым блоком, следующие наборы — после предыдущих. Названия наборов показаны компактными разделителями при наличии нескольких наборов.

Проверено: реальный Y.Doc с 18 задачами и второй задачей «1», старая сохранённая последовательность, идемпотентность восстановления, переименованные/удалённые вкладки; HTTP-повторения второй/третьей попытки в обоих режимах, перезагрузка, защита перенесённых ответов, отсутствие повторных наград, сохранность истории, составные ответы, изменение условия и учительское одобрение. Интерфейс проверен в скрытой встроенной вкладке с настоящими компонентами, сборка и адресный ESLint проходят.

В расширенном прогоне старый `mockExamCorrections.integration.test.js` останавливается на запрете ученику решать нетекущий пробник (`MOCK_HISTORY_READ_ONLY`). Тот же сбой воспроизведён с исходным `server/index.js` из HEAD до этих изменений. Новые тесты коррекции и переноса используют текущий назначенный пробник и проходят.
