# Встречи по ссылке

Публичная страница: `/meetings`. Ссылка на неё есть на экране входа и в разделе преподавателя «Встречи по ссылке».

Человек без аккаунта вводит имя и необязательное название встречи. Он получает комнату и ссылку вида `/?meeting=<uuid>`. Друзья открывают ссылку, вводят имя и нажимают «Войти во встречу». Звонок подключается сразу, без отдельного экрана подготовки. Камера и микрофон изначально выключены. До 20 участников вместе с организатором, камера, микрофон и демонстрация экрана используют существующий CallSection и обязательный TURN relay.

Светлый интерфейс подключённой комнаты сохранён. У публичного организатора приглашение и список участников раскрываются кнопками в компактном заголовке; завершение для всех доступно в меню управления.

Организатор может закрыть/открыть вход, выключить микрофон участнику, отключить участника и завершить встречу для всех. Выключенный микрофон участник может снова включить самостоятельно. Закрытый вход допускает восстановление уже выданного доступа. Завершённая встреча не открывается повторно.

## Доступ и хранение

У публичного организатора отдельная ограниченная роль `meeting-host`. Его случайный токен даёт доступ и управление только одной комнатой. Токен и признак входа сохраняются в sessionStorage текущей вкладки; обновление страницы восстанавливает личность и автоматически подключает звонок. После явного выхода обновление не возвращает человека в разговор: нужна кнопка «Вернуться во встречу». Выбранная преподавателем комната сохраняется отдельно для его аккаунта и восстанавливается только среди его незавершённых встреч. Если браузер блокирует автоматический звук, появляется кнопка «Включить звук».

При передаче обычной ссылки человек получает роль гостя. Ни организатор, ни гость не получает доступ к кабинету преподавателя, ученикам, конспектам, расписанию, уведомлениям или совместному коду. Данные встречи не пишутся в историю занятий и не запускают учебную запись.

В `guest-meetings.json` хранятся хеши токенов и хеш источника создания, без сырых IP-адресов. Ссылки/доступ действуют 24 часа, публичные комнаты удаляются из хранилища при следующей записи спустя сутки после окончания срока. Преподавательские встречи сохраняют прежнюю историю.

## Ограничения

- `PUBLIC_MEETINGS_ENABLED=0` запрещает создавать новые публичные комнаты. Ранее созданные комнаты и преподавательские встречи продолжают работать.
- `PUBLIC_MEETINGS_MAX_ACTIVE` — лимит незавершённых публичных комнат, по умолчанию 10, допустимый диапазон 1–100. Преподавательские комнаты в этот лимит не входят.
- До трёх незавершённых публичных комнат на сеть; до десяти попыток создания в час и сорока попыток входа в минуту на IP. При доверенном loopback reverse proxy используется IP клиента.
- 19 мест доступны гостям, одно зарезервировано за организатором. Повторный вход той же личности заменяет старое подключение даже в полной комнате.
- До четырёх служебных WebSocket-подключений на личность и 80 на комнату, включая ожидание перед входом.

## Проверка перед публикацией

Автоматические проверки: `node --test server/guestMeetings.test.js server/guestMeetings.integration.test.js server/publicMeetings.integration.test.js`.

Проверка сборки: `node scripts/check-guest-meetings-release.mjs local <build-dir>`; проверка опубликованных статических файлов и публичных API без создания реальных комнат: `node scripts/check-guest-meetings-release.mjs verify <build-dir>`.

Полный релиз через `scripts/release-group-availability-notifications.sh` проверяет отсутствие активной записи перед сборкой и перед перезапуском, выполняет регрессионные проверки и сохраняет старые клиентские chunks для открытых уроков. Обновление только клиента встреч публикуется через `scripts/release-meeting-interface.sh`: резервная копия, проверки, отдельная сборка, сохранение старых chunks и атомарная замена index.html. Перезапуск API и пульта для такого обновления не требуется.

Проверка 20 WebSocket-участников подтверждает вместимость и права доступа, но не заменяет нагрузочный созвон 20 реальных человек с камерами. Такой созвон потребуется перед широкой рекламой публичного сервиса.
