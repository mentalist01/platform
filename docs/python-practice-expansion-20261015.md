# Новая практика Python — 15 октября 2026

152 авторские задачи: 16 в каждой теме 101–107 и 40 в списках, включая 24 генератора списков. Кортежи и последующие темы не изменяются.

Новые задания добавляются в конец банков. Старые идентификаторы, позиции, условия, решения учеников, теория и ссылки домашки сохраняются. Внутри подразделов новые задачи идут после старых.

У каждой задачи есть конкретная цель в условии. Эталонные решения используют только текущую и предыдущие темы; импорт библиотек, функции, рекурсия, словари, множества, кортежи и yield не требуются.

Проверка: scripts/audit-python-practice-expansion.py исполняет решения через точный PYTHON_RUNNER_SCRIPT платформы. Ожидаемые ответы вычисляются отдельными проверочными формулами/алгоритмами в исходнике автора. Кроме примеров есть границы, нули, отрицательные числа, повторы, отсутствие результата и детерминированные дополнительные случаи там, где они полезны.

Автопроверка ввода/вывода проверяет результат, а не запрещает ученику более продвинутый способ решения. Форматирование пробелов проверено отдельно строго; действующий проверяющий платформы сравнивает вывод с нормализацией пробельных символов.
