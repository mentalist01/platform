# Маршрут группы и подбор индивидуальных учеников

Активная группа представлена одним пунктом в поиске плана, с числом участников и общей постоянной доской. Её активные участники исключены из списка индивидуальных целей и подбора. Формирующиеся группы сохраняют индивидуальные цели до старта. Поиск группы поддерживает её название и имена участников.

Общая отметка темы, части, страницы и подготовленной задачи хранится в `group-study-progress.json`, отдельно от личных маршрутов. Доступен только преподаватель собственной активной группы. Данные участников не копируются и не перезаписываются. В обычной общей доске группы доступен тот же контрол маршрута; текущая подготовленная задача запоминается для всей группы. Предпросмотр использует постоянную тетрадь группы без старта урока, вызова или изменения отметок. Бейджи участников активной группы показывают её общий маршрут.

Групповые переходы используют существующий механизм журналирования и разделения наборов на части. Новые страницы и проекция кода создаются в `board-group-*` / `collab-group-*`, а не в личных комнатах. Продолжение восстанавливает страницу и задачу в групповой тетради; при обычном переходе в урок используется существующий выбор занятия группы.

В плане раскрывается панель «Подобрать пары и группы»: выбор учеников, просмотр досок, сравнение темы/части, последние задачи и даты отметок, число отмеченных пройденных частей. По умолчанию подбираются одинаковые тема и часть; отдельно можно разрешить соседние этапы. Завершённая часть сравнивается по следующему этапу. Разнесённые части №26 учитывают настоящий порядок маршрута. Неотмеченные, неизвестные и полностью завершившие маршрут ученики не приравниваются к начинающим.

Динамическое программирование по порядку маршрута максимизирует число подобранных выбранных учеников, затем минимизирует разброс этапов. Размер состава — от пары до группы максимум из 8 человек. Участники каждой рекомендации находятся в пределах выбранного разброса, без цепочек далёких соседей. Никакие утверждения о способностях, расписании или темпе из номера этапа не выводятся.

Из предложенного либо собственного состава открывается отдельное окно с именами, темами и редактируемым названием. Создание использует существующий атомарный API мини-групп с `studentIds`, проверкой преподавателя и занятости участников. Группа до старта, расписание и финансовые параметры не меняются. При потере ответа восстанавливается только существующая не начатая группа с тем же названием и точным составом. Участники уже подготовленной группы остаются доступны для сравнения, а повторное создание блокируется интерфейсом и сервером.

Проверка: 58 тестов — доступы и приватность группового маршрута, версии, страницы, групповые переходы, изоляция личных отметок, соответствие выбранного состава, создание до старта, отклонение чужого ученика, восстановление после потери ответа, режимы и ограничения подбора, разнесённые этапы и прежние индивидуальные сценарии. ESLint изменённых модулей чист; новых диагностик App.jsx нет.

Во встроенном браузере на изолированных данных проверены: одна строка группы вместо двух участников, её реальная общая доска, сохранение общей темы, две пары из четырёх совпадающих учеников, отдельные неопределённый и непарный ученики, режим групп до 3 человек с соседними этапами, подтверждение состава и создание выбранной пары. Файл группы содержит двух выбранных участников и статус `ready`; личный маршрут каждого сохранил прежнюю версию. Боевые группы для проверки не создавались и темы за преподавателя не угадывались.
