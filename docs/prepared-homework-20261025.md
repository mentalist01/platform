# Задачи с урока в домашней работе

На подготовленной карточке учитель нажимает «На дом». Снимок задачи попадает в серверную корзину подготовки ДЗ выбранного ученика или группы. Это ещё не выдача: в конструкторе учитель видит условие, добавляет остальные цели и срок, затем выдаёт домашку обычной кнопкой. Повторный клик не добавляет дубликат.

Ученик видит отдельную цель «Дорешать с урока · ЕГЭ №… · название» в домашке и главном блоке дня. «Продолжить решение» открывает личные доску и редактор кода с условием, файлами и начатым решением. Снимок включает близкие записи на доске и сохранённую таблицу. Последующие изменения урока не переписывают домашнюю копию.

Для группы создаётся независимое прохождение для каждого получателя после публикации задания. Выбор отдельных получателей и черновики группы сохраняют прежнюю семантику. У ученика нет доступа к чужим копиям; у преподавателя — только к своим ученикам. Верные ответы передаются только преподавателю. Приватные комнаты не подключаются к общему WebSocket доски.

Код, ввод, вывод и рисунки автоматически сохраняются с ревизиями; резервный локальный черновик переживает закрытие окна. При конфликте другого окна предлагается выбрать серверную или локальную версию. Входные файлы задачи автоматически передаются в Python. Помощник таблиц сохраняет личный файл и запись в конспектах, не меняя общий файл урока. Учитель открывает личную работу из домашки ученика или из панели выполнения группы.

Простое открытие и загрузка таблицы не завершают цель. Нужен проверенный правильный ответ, все независимые вопросы либо ручное принятие преподавателем. Результат проецируется сервером из приватного прохождения, а не принимается из клиентского поля выполнения. Цель учитывается в прогрессе, сроках, отчётах, переносе незавершённого и сундуке за ДЗ; она не засчитывается как решение на живом уроке. Закрытие групповой домашки блокирует запись, проверки и активные сессии помощника; сохранённая работа доступна для чтения, продление возвращает приём.

Хранилище `prepared-homework/`: отдельные неизменяемые снимки, отдельный файл рабочей копии и компактный индекс. Нет массовой миграции существующих наборов, уроков или домашних работ. Учительские токены не сохраняются в копиях URL доски. До 50 целей на одну выдачу.

Проверка: 443 регрессионных теста; 7 заключительных тестов нового сценария; ESLint изменённых компонентов и производственная сборка. Во встроенном браузере проверены очередь «На дом», форма выдачи, ученическая карточка, запуск Python с `17.txt` (вывод `2 100`), автосохранение, повторное открытие, рисование и 100% выполнения с обычным сундуком. Старые тестовые сценарии штрафов получили явные 9 проведённых уроков и план из 4 домашних работ, чтобы не зависеть от адаптационного периода и текущего календаря. Тест снимков прогресса исключает каталоги из чтения файлов.
