# Готовые решения задач набора

В редакторе каждой задачи есть необязательный блок «Готовое решение». Преподаватель загружает до восьми файлов с компьютера либо выбирает их из конспектов этого номера ЕГЭ. Поддерживаются таблицы Excel/Calc, CSV/TSV, PDF, TXT, Python и ZIP до 64 МБ на файл. Файл из конспектов копируется при сохранении: дальнейшие изменения исходного материала не меняют опубликованный разбор.

На доске ученик видит закрытый блок без названия файла и ссылки. Весь файл становится доступен после статуса `solved`: правильной проверки всех полей либо подтверждения преподавателем при ручной проверке. Неверный ответ, частичный успех и пропуск не открывают решение. В группе результат общий, в домашних копиях — личный. Преподаватель с правом управления доской может скачать разбор заранее.

Скачивание проверяет доступ к доске, принадлежность файла конкретной карточке и её результат на сервере при каждом запросе. Ссылки на общий endpoint assets не предоставляют ученику обходной доступ. Ответ скачивается как attachment с private/no-store. Блок использует существующий Blob download, чтобы не выгружать урок и звонок.

`referenceSolutions` хранится отдельно от входных `attachments` и ученических `solutions`/истории/попыток. Разбор не передаётся в Python или редактируемый помощником файл. Автосохранение редактора, копирование между преподавателями и личные домашние копии сохраняют ссылки. При копировании создаются собственные asset ID; приватные ID конспектов автора не передаются. Обновление уже открытого урока выполняется штатной кнопкой «Сохранить и обновить урок» и не сбрасывает ответы, код, историю файлов и координаты условия.

Проверки: `server/preparedReferenceSolutions.test.js`, `server/preparedReferenceSolutions.http.test.js`; регрессии layout, set update, exchange, homework, autosave. Через настоящий React-редактор проверены загрузка кириллического имени, сохранение и скачивание. На карточке при неверном и верном ответе положение изображения совпало до пикселя; скачивание оставило урок на странице. Данные учеников в production для проверки не менялись.
