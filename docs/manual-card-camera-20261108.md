# Камера карточки в конструкторе набора

В библиотеке откройте набор → «Конструктор набора». Выберите карточку,
передвиньте холст рукой или правой кнопкой мыши и настройте масштаб колесом
либо кнопками +/−. «Задать камеру» запоминает текущую видимую область для
этой карточки. Та же кнопка перезаписывает ракурс.

«Показать ракурс» восстанавливает вид в конструкторе. «Авто» очищает только
камеру; размер и раскладка остаются. «Воспроизвести» использует сохранённые
ракурсы. Работает для задач, картинок теории и интерактивных карточек.
Старые наборы сохраняют прежние автоматические настройки до их изменения.

Камера хранится в `boardLayout[key].camera` как прямоугольник x/y/width/height
в единицах ширины выбранной карточки относительно её начала. Перенос,
масштабирование и копирование набора не привязывают ракурс к старым пикселям
экрана. Данные проверяются общим нормализатором на клиенте и сервере.

На уроке прямоугольник восстанавливается относительно фактического якоря
карточки. Участники получают одинаковые данные через существующий API и
механизм переходов. На другом соотношении сторон кадр вписывается целиком
и центрируется в доступной области доски ниже управления. Камера не открывает
ещё не показанные карточки и не меняет позиции объектов. Отдельных таймеров,
опроса сервера или передачи видео для этого нет.

Проверки: захват/воспроизведение произвольного сдвига и приближения, перенос
и масштабирование якоря, четыре размера экрана, валидация, сохранение после
перезапуска, копирование набора, сброс, совпадение данных учителя и ученика.
В интерфейсе изолированного урока проверены захват без скачка, восстановление
после открытия конструктора и переход ученика к следующей карточке.
