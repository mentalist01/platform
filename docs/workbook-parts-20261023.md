# Части задания для решений таблиц

Настройка: «Конспекты» → нужное задание с таблицами → «Части задания», в шапке возле выбора ученика. От 1 до 12, по умолчанию 1. Число хранится по teacherId/taskNumber в workbook-parts.json, распространяется на учеников этого преподавателя. Студент видит настройку своего учителя, менять её не может. Новых прав доступа настройка не даёт.

Установленный Windows/Mac помощник и протокол обмена/загрузки остаются прежними. После первого Ctrl+S помощник спрашивает название. Сервер принимает и надёжно сохраняет байты и идентичность нового решения. При нескольких частях решение получает workbookPartPending:true и остаётся в корневой папке «Решённые задания». На платформе при возвращении в окно/видимую вкладку (или следующей лёгкой проверке через 15 секунд) появляется выбор части. До выбора файл доступен и не теряется. В приложении LibreOffice собственное окно выбора не добавляется, помощник переустанавливать не требуется.

Выбор создаёт или использует подпапку «Часть N» под «Решённые задания» соответствующего ученика/задания/категории. Меняются только folderId,folderName,workbookPartNumber,workbookPartPending; ID, имя, байты, ревизия, хеш, привязка helper и автор сохраняются. POST использует ту же блокировку workbookSolutionKey, что и загрузки, и перечитывает строку внутри блокировки. pendingOnly предотвращает перемещение уже распределённого файла запоздавшей второй вкладкой. Повторный Ctrl+S сохраняет выбранную папку. Старые решения без метаданных части также сохраняют своё расположение.

Кнопка «Выбрать позже» оставляет доступную кнопку внизу страницы для возврата к распределению. Окно показывает только файлы, сохранённые текущим пользователем, в пределах доступных ему учеников. Учитель видит имя ученика. Решения учителя к вопросам остаются защищены от редактирования учеником. При нескольких ожидающих файлах окна идут по одному. Если учитель вернул одну часть, ожидающие файлы распределяются в корень без дополнительного вопроса. Существующие папки частей не удаляются при сокращении числа, повторное сохранение ранее распределённых работ не переносит их.

Одинаковые имена новых решений при нескольких частях разрешены: физические имена и ID уникальны, файлы не перезаписывают друг друга. В обычном режиме одной части прежняя проверка одинаковых имён сохраняется. Одноразовое указание названия и дальнейшая синхронизация старого помощника работают без изменений EXE и без нового скачивания учениками. Переустановка, отключение антивируса или изменение доверия Windows не требуются.

Проверки: старый helper User-Agent 1.2 и прежний multipart; по умолчанию одна часть; настройки и изоляция двух преподавателей; только свои/доступные ученики; сохранение байтов до выбора; одинаковые имена в двух частях; выбор одновременно с загрузкой; повторные Ctrl+S; две вкладки; сохранение старых папок; сокращение числа частей; собственные сохранения преподавателя. Дополнительно прежние тесты helper, teacher notes, question workbooks, сжатия FODS и установки.
