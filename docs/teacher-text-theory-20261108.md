# Личная текстовая теория набора

«Текст учителя» доступен в списке наборов, редакторе набора и меню текущего
набора на доске. Открывается отдельное окно, которое можно держать на втором
мониторе. Вставка Ctrl+V принимает форматированный HTML либо Markdown из
кнопки копирования ChatGPT. Сохраняются заголовки, списки, таблицы, выделения
и код. Есть автосохранение, Ctrl+S, режим чтения и увеличение всего текста.

В приложении Windows 0.1.16 окно создаётся скрытым, включается
`setContentProtection(true)`, затем показывается пустое защищённое окно.
После композиции Windows в него загружается страница с личным текстом.
Если защиту включить не удалось, текст не загружается. При наличии второго
монитора окно размещается на нём; открытое окно набора повторно используется.
Настройки захвата, сцены OBS, звонок и основная вкладка не переключаются.
Обычный браузер не может включить защиту окна от захвата: используйте второй
монитор вне записи или захват только окна урока. На старом приложении кнопка
предлагает обновление, а не открывает личный текст внутри записываемой вкладки.

Источник ограничений захвата:
https://www.electronjs.org/docs/latest/api/browser-window#winsetcontentprotectionenable-macos-windows

Текст хранится в `teacher-theory/` внутри каталога prepared lesson tasks
отдельными файлами. Доступ только владельцу набора через GET/PUT
`/api/lesson-task-sets/:id/teacher-theory`. В списки наборов, снимки урока,
Yjs, очередь карточек и обмен наборами эти данные не попадают.
Сохранение атомарное, с проверкой версии. При конфликте текст в окне остаётся;
черновик хранится на устройстве под ключом пользователя и набора. Есть явное
восстановление черновика. Сервер и браузер очищают HTML: без скриптов,
обработчиков событий, iframe, внешних изображений и опасных CSS. Ссылки
открываются отдельно. Для работы страницы не нужен доступ к ChatGPT.

Верификация: HTTP-доступ владельца и запрет ученику/другому учителю, отсутствие
текста в проекции урока, сохранение после повторного создания хранилища,
конфликт версий, форматирование и очистка HTML/Markdown. В браузере проверены
вставка HTML с таблицей/кодом/цветом и Markdown, чтение после перезагрузки.
В desktop проверяется порядок защиты окна до загрузки текста, общая сессия входа,
повторное использование окна и отказ при ошибке защиты.
