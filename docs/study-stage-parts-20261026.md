# Следующая тема с подстраницами и частями одного набора

После «Завершить текущую часть» открывается окно следующего этапа. Оно показывает родительскую страницу «Задание №9», подстраницы частей, выбранные наборы и задачи. Единственный подходящий набор подставляется автоматически; если вариантов несколько, преподаватель выбирает. Страницу можно явно оставить без набора. Начальная часть становится текущей после «Создать и перейти».

## Объединённые наборы

В редакторе задачи со второй позиции доступно «С этой задачи начинается следующая часть». Маркер сохраняется вместе с обычным автосохранением. Части следуют по порядку задач, начиная с `partNumber` набора. Поиск находит общий набор по каждой входящей части; список показывает все номера частей.

В окне перехода можно разметить общий набор без открытия редактора: выбрать объединённый набор и начальную задачу каждой следующей части. Порядковая позиция помогает различить повторяющиеся названия «1», «2» и т. д. Подтверждённая граница сохраняется в исходном наборе с проверкой его версии.

Существующие прохождения не пересобираются. Новые прохождения части хранят `partFilters` и снимок соответствующих задач с исходными идентификаторами и индексами. Подключение новых задач учитывает фильтр; файлы, ответы, код и ввод Python остаются привязанными к своим задачам. Вводная теория общего набора добавляется перед первой частью.

## Создание и восстановление

Сервер проверяет владение учеником и наборами, доступ к записи на доске, версии наборов и вместимость каталога до создания. Все части готовятся за один подтверждённый переход. Уже связанные страницы используются повторно, существующее содержимое сохраняется.

Промежуточные результаты хранятся в `stageSetup` записи ученика. Ключ создания страницы `study:<operationId>:<part>` делает повтор безопасным даже при сбое между сохранением страницы и подтверждением её в журнале. Повтор продолжает ту же операцию после перезапуска. Если набор изменился, «Изменить подготовку» сохраняет созданные страницы и позволяет выбрать актуальные материалы. Прогресс текущей темы меняется только после успешной подготовки всех частей.

При завершении первой части следующая уже подготовленная подстраница открывается без повторного создания. Названия и порядок общего плана не меняются.

## Проверки

116 тестов: части набора и их индексы, файлы и код, исходный общий набор, фильтрация дополнения очереди, авторизация и версии, создание дерева через HTTP API, повторные запросы, прерывание подготовки и перезапуск, отказ записи журнала, отмена с повторным использованием страниц, каталог досок, теория, домашка, обмен наборами, достижения, ответы и план.

Встроенный браузер: завершение №18, разметка одного набора №9 перед четвёртой задачей, предпросмотр двух частей по три задачи, создание родительской страницы и двух подстраниц, назначение первой части текущей. Диагностика ESLint новых и изменённых модулей без ошибок. Production-сборка использует штатную проверку конфигурации звонка.
