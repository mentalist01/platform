## Что остаётся ограничением

- Предупреждения Windows/антивирусов при новой установке помощника не устранены полностью. Сценарий частей работает с установленной программой, но прямую сборку это не превращает в подписанное приложение из Microsoft Store. В `tools/IvanEge.WorkbookHelper/README.md` это указано; нельзя обещать отсутствие предупреждений.
- Достижения различают темы по номеру ЕГЭ и части. Произвольных отдельных тематических тегов пока нет. Вне расписания два занятия подряд без 90-минутного перерыва могут считаться одним; возврат к пропущенной задаче сейчас считается в другой московский учебный день, а не в следующую встречу в тот же день. Это ограничения учёта, не новые реализованные возможности.
- Старым решениям на групповых досках не начисляются выдуманные награды задним числом: нет надёжных записей о том, кто присутствовал и когда решил. Новая история начинается с выпуска достижений за уроки.

На действующем сервере дополнительно проверены настройки аккаунта Ивана: у №9 и №22 выставлено по две части. Настройки не изменялись при сверке.
